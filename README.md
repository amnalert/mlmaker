# Machine Learning Maker

PySide6 Local GUI Application for creating projects, uploading images, labelling images, and data injection into nf-core-yolopt pipeline for automatic machine learning training and validation.

## Dependencies

- PySide6
- Nextflow(eventually)
  - All dependencies from [amnalert/nf-core-yolopt](https://github.com/amnalert/nf-core-yolopt)

### Installation

- For now, just download the source code and run:

```Shell
pip install pyside6 # (if not installed. recommended virtual environment)
python app/main.py
```
